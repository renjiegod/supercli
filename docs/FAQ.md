# FAQ 与故障排查

## 为什么有些工具显示“未计分”？

没有可比的官方 GitHub 仓库就不填分数，仍然可以搜索、查看文档和参与收录。

## 为什么换仓库后构建失败？

指标绑定原 repo。确认官方来源后运行 pnpm sync，核对快照差异，再构建。

## GitHub 同步遇到限流怎么办？

使用本机已登录 gh：node scripts/sync.mjs --gh --icons。也可以向子进程注入 GITHUB_TOKEN，不要落盘或提交密钥。

## 安装按钮为什么打开详情？

部分工具没有经过确认的一行安装命令，会引导到官方文档，不生成猜测命令。

## 剪贴板不可用怎么办？

页面会打开详情并提示手动复制；浏览器可能限制非安全上下文或未授权的剪贴板访问。

## 图标同步失败怎么办？

检查文件名、目录和来源；同步拒绝符号链接及越界路径。不能关闭安全校验绕过错误。

## 为什么没有自动审核？

首期明确采用人工审查。手动检查工作流只运行类型、数据、测试和构建，不审核或批准 PR，也不会自动合并。
