# v0.3.0 社区参与流程验收

2026-10-20。实现 GitHub Issue 推荐与信息修正表单、PR 路径、最近收录、收录维护及推荐署名。复用 GitHub 登录，不另建 OAuth 或保存用户令牌。

## 事实与边界

历史 90 条目逐项对照首次 commit 3c4e05a，ID 与时间一致；推荐者均为 null。展示维护者 webkubor，社区推荐区保留真实空态。署名由投稿者明确选择；不署名只保留公开投稿链接。维护者人工核验、合并和发布，线上确认后才标为已收录。

GitHub 已创建待核验、需补充信息、已收录三种标签；推荐与修正表单默认待核验。用户另授权 Codex 每小时检查新 Issue/PR 并通知，状态 ACTIVE；通知自动化不评论、不审核、不合并、不部署。GitHub 检查与部署工作流仍仅支持手动触发。
