# v0.3.1 视觉与交互细节验收

2026-10-21。近期优先级按用户确认：用户体验与视觉感受；每轮围绕真实浏览、筛选、复制、详情及手机操作打磨。

## 本轮结果

保留 Swiss 蓝白品牌与既有 Logo，强化首页主操作、浅蓝工具预览、卡片图标容器与焦点/悬停层次。工具预览随指针或键盘焦点同步名称、命令及复制目标，新增复制成功就地确认。详情安装命令及官方链接优先展示，统计说明原生折叠，质检辅助入口后移。

原生 dialog 保留 Escape 与焦点恢复，新增遮罩关闭（按下与点击均需在面板外），打开时锁背景滚动。手机关闭入口44px且可随正文滚动保持可达。入场只覆盖前六张卡且最多150ms错峰，结束后释放 transform 控制权；减弱动效禁用新进场与位移。

## 验证

- 22 项测试、严格类型、目录快照契约及构建通过；23 组配色对比全部通过。
- 独立代码审查与详情布局补充审查通过；采纳预览操作说明的 aria-describedby。
- Ego 实测键盘聚焦预览、复制对应命令、连续复制恢复、切换工具清除旧反馈。
- 受控剪贴板 Promise 验证：复制 A 未完成即切到 B，A 完成不把 B 标成已复制，保留 B 的辅助标签。
- 遮罩关闭、Escape、焦点回归、背景滚动锁定、拖选正文到外部不误关、正文滚动后关闭入口仍可见。
- 来源默认折叠、Enter 展开/收起，安装内容不被折叠，安装与官方链接顺序位于质检之前。
- 390/768/1280/1600px 无横向溢出；卡片标题最窄286px；手机弹窗宽358px，关闭入口44px。
- 卡片入场结束仍可悬停上移3px；系统减弱动效时弹窗 animation=none。
- 人工截图与本地 VLM 未发现布局重叠或横向截断；agent-eyes 无运行错误。
- cs ui 已记录本轮前后渲染计量，字体体系与品牌色保持同一真源。Scorecard 页面评分不作为视觉体验评分。

浏览器自动化若后台 Page 未获得窗口焦点，元素 activeElement 可变化而不派发 focusin；验收需先 Page.bringToFront。此为测试环境焦点问题，不通过篡改产品焦点逻辑规避。
