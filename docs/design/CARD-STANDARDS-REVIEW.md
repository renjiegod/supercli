# 卡片来源与公开收录标准验收 · v0.4.0

- 来源标签统一采用图标、紧凑胶囊与同等层级：厂商官方 / 社区项目。来源不表示质量或授权。
- 卡片新增收录与核验入口，点击展开详情中的原生 details，并将焦点移至 summary；支持 Escape 关闭详情。
- `/standards` 公示来源、安装、用途限制、维护、复核记录五项标准，并区分资料核对、安装实测、范围待补充。
- DYT AShare CLI 仅有两项资料核对，依据为 PR #2 审核记录及核验时的固定版本 README；不声明独立安装通过。其余历史工具展示待补充及原始收录出处。
- 核验记录绑定名称、维护方、来源类型、用途、仓库、文档和安装命令；目录变更后旧记录失效，构建也会阻止不一致数据。
